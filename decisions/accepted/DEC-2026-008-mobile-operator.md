# DEC-2026-008 — Lilith Mobile Operator

**Status:** Accepted  
**Date:** 2026-08-02  
**Authority:** John

## Decision

Lilith will include a controlled mobile execution layer using iPhone, Siri, AirPods, Apple Shortcuts, App Intents, Messages, and approved APIs.

## Reason

John needs voice-first and mobile execution that reduces app switching and closes routine communication loops while preserving safety, identity, and organizational boundaries.

## Permission Levels

- Draft Mode
- Trusted Mode
- Campaign Mode

## Boundaries

The subsystem will not use random-number messaging, broad unattended replies, plaintext credentials, undifferentiated relationship behavior, or claims of unrestricted phone control.

## Consequences

- Mobile execution becomes part of the canonical Lilith architecture.
- Existing shortcut work becomes reference material rather than authoritative behavior.
- Communication actions require verified completion and an audit record.
